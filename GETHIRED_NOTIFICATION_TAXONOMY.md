# GETHIRED NOTIFICATION TAXONOMY — RECENT DEPLOYMENT
See main NOTIFY report. Summary of notification types used in recent deployment:

## Types in JAC Modal
1. **Toast/Snackbar** — "Link copied!" (success, 2.2s)
2. **Inline loading** — skeleton shimmer chips
3. **Inline status** — status chip (published/draft/etc.)
4. **alertdialog** — delete confirmation panel
5. **Action description** — disabled share reason

## Types in V7 Job Detail
6. **role=status** — boilerplate fallback notice
7. **role=alert + aria-live=assertive** — job load error state
