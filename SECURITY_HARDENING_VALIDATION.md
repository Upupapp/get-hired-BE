## Firebase Init Source Type Expected in Logs

When `FIREBASE_SERVICE_ACCOUNT_BASE64` is set (recommended for Linode):

```
Firebase Admin: initializing via env-base64
```

Alternative source types (depending on which env var is set):

| Env var set | Log output |
|-------------|-----------|
| `FIREBASE_SERVICE_ACCOUNT_BASE64` | `Firebase Admin: initializing via env-base64` |
| `FIREBASE_SERVICE_ACCOUNT_JSON` | `Firebase Admin: initializing via env-json` |
| `GOOGLE_APPLICATION_CREDENTIALS` | `Firebase Admin: initializing via application-default` |
| `FIREBASE_SERVICE_ACCOUNT_PATH` (dev only) | `Firebase Admin: initializing via local-dev-file` |

If none of these appear and the application exits, check that at least one
of the above environment variables is set in the PM2 environment or the
system environment.
