# GETHIRED BRAND VISUAL DIRECTION — RECENT DEPLOYMENT

## JAC Modal Visual Direction

The Job Action Command Center follows the approved GetHired employer command center aesthetic:
- Deep Navy header (#1a1830) — authority, clarity
- White body cards — clean, modern
- Coral primary accent (#FF7062) — action-oriented
- Azure secondary (#6C6BAD, #DDD8F0) — supporting
- Red danger zone — clearly destructive, separate from other actions
- Status chips — color-coded: green=live/published, amber=draft, red=expired, gray=archived
- Skeleton shimmer — "something is loading" without blank space

## What the modal should feel like:
- Fast: skeleton → real data in <500ms typical
- Confident: each action has a clear label + description
- Safe: delete is at the bottom, separated, has friction (confirm panel)
- Trustworthy: counts are real from DB, not fake
- Modern: hover lift on action rows, bottom-sheet on mobile

## Visual guardrails (applied):
- No fake applicant counts ✅
- No "AI-powered" claims ✅
- No fake urgency signals ✅
- No cyberpunk glow effects ✅
- No casino-like animations ✅
